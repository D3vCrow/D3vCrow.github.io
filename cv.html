Approach

How I Work with AI

Unity is hands-on — I write the C#, I debug the edge cases, I own every system. That part doesn’t change.

For everything else — web apps, Python tooling, localization, research — I direct. Not casually. I’ve built a Claude Code environment from scratch: project-scoped standards that define how agents work on my code, a persistent memory system that carries context between sessions, custom skills for specific workflows, and review agents that catch what I’d miss alone.

I write the spec. AI writes the code. I read every diff. If I can’t explain what was built and why, I don’t ship it.
