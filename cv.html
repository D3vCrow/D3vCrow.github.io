Approach

How I Work

My Unity work is hands-on — I write the C#, I own the systems, I debug the edge cases. For everything outside Unity (web apps, Python scripts, tooling), I direct AI to build. I architect the solution, write the specification, review every output, and iterate until it's right. I don't pretend to write it all by hand — that's the honest part.

Step 01

Architect

Define the structure, data flow, and constraints before a single line of code is written.

Step 02

Specify

Write detailed prompts and specs. The quality of the output depends entirely on the quality of the input.

Step 03

Review

Read everything. Test everything. Understand what was built — not just whether it works.

Step 04

Iterate

Refine, fix edge cases, improve. Keep going until it's right. The AI is the tool — I own the result.
