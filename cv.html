Approach

How I Work with AI

Unity is hands-on. I write the C#, debug the edge cases, own every system.

For web apps, Python tooling, localization and research, I direct AI. I’ve built a Claude Code environment over the past year: project-scoped standards that define how agents work on my code, a persistent memory system that carries context between sessions, custom skills for specific workflows, and review agents that catch what I’d miss alone.

I write the spec. AI writes the code. I review every diff. If I can’t explain what was built and why, I don’t ship it.

Stack: Claude Code · Claude API · Cursor · ChatGPT / GPT‑5 · Playwright · MCP tools · Midjourney · Sora

This portfolio was architected and reviewed by me, written by directed AI, iterated until shipped. The setup improves with every project.

Why it matters: you hire one person who delivers across Unity, web, and tooling. The AI setup is how that works at production quality.
