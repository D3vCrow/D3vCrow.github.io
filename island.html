Systems

Survival Built From First Principles

Four systems carry the weight of the prototype, each treated as a small piece of engineering rather than a feature toggle.

01

Verlet-Rope Fishing Line

A fishing rod with a real rope, simulated by Verlet integration. Each segment is a point with position + previous-position; constraint passes hold segment length under tension, gravity, and water drag. The line bends, slacks, and tugs without a cloth system, written from scratch in RopeSimulator.cs.

02

Event-Driven Thirst Loop

Thirst, hydration, and consumption listeners are decoupled via C# events. Drinking, UI updates, and survival debuffs all subscribe to the same broadcast, no polling, no Update-tick coupling. Adding a new consumer is one subscription, not a refactor.

03

Burst-Compiled Character Mechanics

One [BurstCompile] component holds push physics, animator layer blending, and pickup state on the same hot path. Movement and interaction stay in one place so frame-time stays predictable, and the math on hot ticks compiles to tight native code instead of managed allocations.

04

Singleton Typology + Pipeline

Scene-spanning state organised as DDOL / Dominant / Regulator singletons, each with a different lifetime contract instead of one global blob. Lighting baked with Bakery for HDRP fidelity at runtime cost, audio routed through FMOD for adaptive mixes (ambient, weather, combat layers).

Highlight

Lab, Not Demo

Island Project is a working surface for the systems I want to keep sharp, ropes, events, Burst, lighting, audio routing, all in the same scene so they have to coexist. It's in-development on purpose: each iteration is a chance to swap one piece, watch what breaks, and write down what I learned.
