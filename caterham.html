Caterham
Car Configurator

A live web configurator delivering every Caterham spec on the market through a real-time rendering backend. I owned the full pipeline from raw 3D data to the browser window. Still own it, post-Renderapp closure.

Scope

Full Pipeline Ownership

The role was labelled Product Owner, but the reality was sole engineering accountability: 3D ingestion, Unity render setup, build pipeline, Node.js middleware, Azure deployment, and client-facing technical comms.

01

3D Data Ingestion

Bringing Caterham's CAD and 3DS Max assets into a Unity-ready format, keeping the geometry clean while staying inside strict web delivery budgets.

02

Unity Render Setup

Lighting, materials, and render settings tuned for realism under tight web build constraints. The quality bar had to match Caterham's brand, not "good enough for web".

03

Custom Editor Tooling

Unity editor tools for QA, config validation, and pipeline automation. These kept a one-person pipeline running at scale.

04

Node.js Middleware

Server-side glue between the Unity build and the configurator frontend. Config data, state, and delivery orchestration.

05

Azure Deployment

Cloud build and delivery pipeline on Azure. Live product, real customers, real accountability. Every deploy went straight to production.

06

Client Communications

Direct technical communication with Caterham: scope, trade-offs, delivery timelines. The work extended past code into stakeholder management.

Highlight

The Work Followed Me

Renderapp closed at the end of 2024. Within months, former leadership reached out to keep the Caterham configurator going independently. Same role, same client, same product, no agency layer. The latest US Phase 1b locale launch shipped from this independent arrangement. Continuity through company closure is the part I'm proud of.
